# Student Learning Tracker 📚
To track student activity...
A responsive student productivity dashboard built with **HTML, CSS, and vanilla JavaScript**. Organize courses, plan study tasks, and monitor progress from one simple interface.

## Features

- **Dashboard:** Overview of courses, tasks, completed work, and overall task completion.
- **Course management:** Create, edit, search, and delete courses.
- **Study task management:** Create, edit, delete, and complete tasks.
- **Task details:** Add a related course, due date, priority, and optional notes.
- **Filters:** Search tasks and filter by status or priority.
- **Progress indicators:** View course progress and overall task completion.
- **Local storage:** Your changes are saved in the current browser.
- **Responsive design:** Layout adapts to desktop, tablet, and mobile screens.
- **Starter data:** Explore the dashboard immediately with sample courses and tasks.

## Built with

- HTML5
- CSS3
- Vanilla JavaScript (ES6+)
- Browser `localStorage`

No frameworks, package installation, backend server, or database setup are required.

## Getting started

### Option 1: Open directly

1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Start adding your courses and study tasks.

### Option 2: Run with VS Code

1. Open the project folder in Visual Studio Code.
2. Install the **Live Server** extension if it is not already installed.
3. Right-click `index.html` and select **Open with Live Server**.

## How to use

1. Open the **Dashboard** to see your learning overview.
2. Choose **My Courses** and select **Add course** to create a course.
3. Choose **Study Tasks** and select **Add task** to plan your work.
4. Mark a task's checkbox when it is complete.
5. Use search and filters to find courses and tasks.
6. Edit or delete records using the action icons.

## Data and privacy

This is a front-end college mini project. Data is stored locally in your browser with `localStorage`. It does not have user accounts, cloud sync, or a shared database. Clearing browser site data or using a different browser/device may remove or not show your saved information. The initial sample data is loaded when no saved project data exists.

## GitHub upload

1. Create a new repository named `student-learning-tracker` on GitHub.
2. Keep the repository public if you want to show it in your student portfolio.
3. Upload `index.html`, the `css` folder, the `js` folder, and this README.
4. Open `index.html` in GitHub to inspect the source files.
5. To publish it, open **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/(root)`, and save. GitHub Pages may take a few minutes to publish the site.
